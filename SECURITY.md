# Security Policy

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability.

Email [michelangelolattanzio@gmail.com](mailto:michelangelolattanzio@gmail.com)
with the subject `NumeralSystems.Net security report`. Include:

- the affected version or commit;
- the vulnerable API and required input;
- reproduction steps or a minimal proof of concept;
- the impact you believe is possible;
- any suggested mitigation;
- whether the report may be credited publicly.

Avoid accessing data that is not yours, disrupting services, or publishing the
details before a fix can be prepared.

## What to expect

The maintainer will acknowledge the report when possible, investigate it, and
coordinate remediation and disclosure with the reporter. Response time is not
guaranteed because this is a community-maintained project.

Security fixes are made against the latest development state. Older builds may
not receive patches; users should update to the newest fixed release or commit.

## Non-security bugs

Crashes, incorrect conversions, documentation errors, and performance problems
without a security impact belong in the public
[issue tracker](https://github.com/MiLattanzio/NumeralSystems/issues).
